# NexusLang — اردو (Urdu)

NexusLang es el primer lenguaje ES/EN con soporte nativo de Urdu.
NexusLang پہلی دو لسانی زبان ہے جو اردو کو native زبان کے طور پر سپورٹ کرتی ہے۔

## Run / چلائیں
python nexuslang.py hola_urdu.nx

## Keywords / کلیدی الفاظ
| Urdu | Meaning |
|---|---|
| اگر / ورنہ | if / else |
| جب تک | while |
| ہر ... میں | for ... in |
| فعل | function |
| واپس | return |
| دکھاؤ | print |
| متن / لمبائی | str / len |
| درست / غلط | True / False |
| خالی | None |

## Example / مثال — hola_urdu.nx
فعل سلام(نام):
    دکھاؤ("سلام " + نام + "!")
سلام("پاکستان")
